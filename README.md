# Esmire

Клиентский мод для **Minecraft 1.21.4 (Fabric)** в стиле Liquid Glass.

## Установка
1. Установите **Fabric Loader** (>= 0.19.3) и **Fabric API** для 1.21.4.
2. Скачайте актуальный .jar из [Releases](https://github.com/tragicmagne/Esmire/releases/latest).
3. Положите файл в папку .minecraft/mods.

## Автообновление
Мод автоматически проверяет новые версии через update.json, сверяет SHA-256 и перекидывает вас на сайт + открывает папку с модами.
